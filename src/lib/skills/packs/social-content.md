# Social Content Strategy Playbook

Vary the angle. Posts feel samey when each is a feature pitch in a new font. Each post: ONE pillar, ONE angle, ONE funnel job.

## Content pillars (rotate, don't repeat)
Anchor each post to one of 4-5 pillars for range. Default mix:
- Educational (30%): how-to, framework, tip, myth-bust. Teach, don't sell.
- Behind-the-scenes (20%): how it's made, a build decision, an honest tradeoff.
- Social proof (20%): a result, a before/after, a user quote, a use case.
- Perspective (20%): a contrarian take, a trend, a "stop doing X."
- Promotional (10%): a direct offer. Earn it with the other four.
Pick a different pillar than the last post used.

## Angle variety (anti-sameness checklist)
Same product, different lens:
- Problem-first ("tired of X?") vs outcome-first ("imagine X").
- Audience swap: one feature framed for a beginner vs a pro vs a skeptic.
- Format swap: question, bold claim, list, story, stat, comparison, confession.
- Emotion swap: aspiration, frustration, curiosity, relief, FOMO, humor.
- Zoom swap: one tiny detail vs the big promise.
If a new post shares angle AND emotion with the last, change one.

## Shareable, saveable, commentable
Each post earns at least one:
- Shareable: gives the sharer status ("I'm smart/funny/in-the-know"). Bold take, surprising stat, relatable truth.
- Saveable: future utility. Checklist, step list, "steal this." People save what they'll reuse.
- Commentable: leaves a gap. A real either/or, an invited hot take, a question hard to scroll past.
Pull angles from the product's real benefits and proof, never generic filler.

## One idea, many posts (repurpose)
Spin 5+ posts from one insight by changing the atom: quotable claim (one bold line), tactical tip (the how), story (setup, problem, result), data point (a number reframed), contrarian angle (what everyone gets wrong). Each must stand alone.

## Map every post to the funnel
- Awareness: broad pain or curiosity, no jargon, zero ask. Goal = stop the scroll. No hard CTA.
- Consideration: mechanism, proof, comparison, "how it works." CTA = learn more, see example.
- Conversion: specific offer, urgency, clear next step. CTA = direct action.
Most posts are awareness or consideration. Hard CTAs everywhere kill reach.

## Decision rules
- Lead with the reader's problem, not the product name.
- One idea per post. Cut the second point into a new post.
- Concrete beats vague: a number, a name, a moment, a before/after.
- If it reads like an ad, reframe as a story, a tip, or a question.
- If it could describe any competitor, rewrite it.

## Anti-patterns
Every post a feature list. The same hook shape twice running. Vague aspiration, no specifics. A hard CTA on awareness content. Telling, not showing. Posts nobody can reply to.
